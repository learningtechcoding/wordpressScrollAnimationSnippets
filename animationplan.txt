===========================================================
Goal: 3 reference sites ki saari animations ko "same to same" WordPress snippets
mein banana, taake baad mein sirf CUSTOM CLASS ya ID laga kar kisi bhi
Elementor element par animation apply ho jaye.

Reference sites:
  A) https://advantumhealth.com/        - WordPress, custom CSS+JS (omythic-child theme)
  B) https://24-7consultancy.pk/        - Laravel, AOS + Slick + jQuery

2. AAP KE MAUJOODA SNIPPETS (jo aap ne bataye)
=====================================================================
 S-EXIST-1  "Scroll Animation" (jo paste kiya)
    - Class: .scroll-animate  +  direction class:
        top-bottom | bottom-top | left-right | right-left
    - Web Animations API (element.animate) + IntersectionObserver.
    - Distance: Y=70px, X=80px, duration 1200ms,
      easing cubic-bezier(0.22,1,0.36,1), rootMargin -15%.
    - Elementor editor mein band (return).
    - Enter par in, EXIT par wapas out (har bar replay hota hai).
    Kamiyan jo mein dekh raha hoon:
      a) Sirf slide hai; fade (opacity), scale, flip, stagger nahi hai.
      b) Element ko pehle se visible rakhta hai (opacity 1), is liye
         jab tak scroll na ho tab tak "off-screen position" par rehta hai.
      c) "once" option nahi (sirf replay-on-exit).
      d) items.find() har entry par - bohat elements par slow; Map behtar.
      e) prefers-reduced-motion support nahi.
      f) Distance/duration sab elements ke liye ek jaisi - per-element
         override (data-attribute / class) nahi.

 S-EXIST-2  "Group all Direction Scroll Animation"  (abhi khali)
 S-EXIST-3  "Header Footer Animation"                (abhi khali)

4. SNIPPET 2 - SCROLL REVEAL TYPES  (A1 + B1 + C ki reveal)
=====================================================================
 Source: A (.scroll-animate-item + .vis), B (AOS 45 elements).

 Elementor mein "CSS Classes" field mein sirf yeh class likhni hogi:

  Direction (A1 + AOS fade-*):
    ax-fade-up | ax-fade-down | ax-fade-left | ax-fade-right | ax-fade
  Existing compat (S-EXIST-1):
    scroll-animate + top-bottom | bottom-top | left-right | right-left
  Scale / zoom (A: scale(0.97), diagram pop scale(0.2)):
    ax-zoom-in | ax-zoom-out | ax-pop
  Flip 3D (AOS flip-right / flip-up):
    ax-flip-right | ax-flip-left | ax-flip-up | ax-flip-down
  Stagger (A: nth-child delays 0.06-0.66s, B: AOS delay):
    PARENT par   ax-stagger  -> bachon ko khud delay milta hai (step 0.06-0.15s)
    ya ax-delay-100 / 200 / 300 ... 1000
  Speed:   ax-fast (500ms) | ax-normal (800ms) | ax-slow (1200ms)
  Distance: ax-dist-sm (20px) | ax-dist-md (50px) | ax-dist-lg (80px)
  Mode:    ax-once (sirf ek bar)  |  ax-repeat (har bar, jaise abhi hai)
  Mobile:  ax-no-mobile (mobile par band)

 Engine: ek IntersectionObserver (A wala rAF scroll loop nahi),
   transform + opacity, will-change sirf animate hote waqt,
   prefers-reduced-motion, Elementor editor mein band,
   fade-right ke liye overflow-x:clip (B ka horizontal scroll bug).

 Extra (A ke patterns):
   - ax-line-draw / ax-image-reveal (clip-path wipe)       [optional]
   - ax-text-split (word/letter reveal)                    [C ke liye, confirm]
   - ax-parallax (data-speed)  [C "Parallax Carousel" ke liye, confirm]

7. PERFORMANCE RULES (naya code lag na kare)
=====================================================================
 - Sirf transform + opacity animate (layout properties: height/top/left nahi,
   jahan max-height ki zaroorat ho wahan grid-template-rows trick).
 - Scroll event ki jagah IntersectionObserver.
 - jQuery .animate() ki jagah CSS transition / WAAPI.
 - Slider autoplay: tab hidden ya viewport ke bahar ho to pause.
 - will-change sirf active animation par, baad mein hata dena.
 - prefers-reduced-motion = animations band.
 - Elementor editor/preview mein sab band (aap ke snippet jaisa).
 - Ek hi IntersectionObserver sab elements ke liye.
 - Images lazy-load (B mein 8/37 lazy nahi thi - WP mein default hota hai).
