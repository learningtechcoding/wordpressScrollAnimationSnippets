Scroll animations, set by class name.

AX Scroll Animation is a single snippet for WordPress and Elementor. Type a class such as ax-fade-up into an element's CSS Classes field and it animates as it scrolls into view. There is no plugin to configure and no JavaScript to write.

Installation guide Browse the effects
  • 40 effects
  • Works on any container, header, footer or card
  • Repeats on scroll up, or runs once
  • Respects reduced-motion settings

Install

  1. Create a snippet. In WPCode (or Code Snippets), add a new HTML Snippet and paste the complete code from the viewer below.
  2. Set the location. Choose Site Wide Header. The snippet hides animated elements before the first paint, so nothing flashes.
  3. Add a class. In Elementor, open Advanced, CSS Classes on a widget or container and type a class, for example ax-rise-3d ax-slow.
  4. Check the live page. Animations are switched off inside the Elementor editor on purpose. Open the preview or the published page to see them.

The complete code

This is the whole snippet: styles and script in one file. Copy it, or download it as an HTML file. The tabs below copy the CSS or the JavaScript on its own.

Using a caching or optimisation plugin? Exclude this snippet from "Delay JavaScript" in WP Rocket, LiteSpeed or Autoptimize. If the script is delayed, animated elements stay hidden until the first interaction.

Effects

Every effect is a single class. Put one effect class on an element, then add modifiers (speed, delay, distance) as needed. Select an effect to see it run, or switch to the gallery to see them all as you scroll.

Speed, delay and distance

Modifiers go next to the effect class and work with every effect: slides, 3D, reveals, text and groups. Speed and duration are the same thing. Numbers are milliseconds.

ClassMeaning
ax-fastest ax-fast ax-normal ax-slow ax-slower ax-slowestDuration of 300, 500, 800, 1400, 2000 and 3000 ms. The default is 900 ms.
ax-duration-NAny duration, for example ax-duration-1700.
ax-delay-NWait N ms before starting, for example ax-delay-350. There is no upper limit.
ax-dist-sm ax-dist-md ax-dist-lgTravel distance of 20, 50 and 100 px. Also ax-dist-N for any value. Default 50 px.
ax-blurFades in from a blur. Works with any effect.

Repeat, once, and mobile

By default every animation plays when the element scrolls into view and plays in reverse when you scroll back up (it starts to reverse while it is still well on screen, once it sinks below 80% of the screen height; change REVERSE_LINE in the script), then plays again on the way down. You can switch any element to play only once.

ClassBehaviour
ax-repeatPlays on scroll down, reverses smoothly on scroll up, and plays again. This is already the default, so the class is optional, but it keeps the element repeating even if you change the snippet's default.
ax-oncePlays one time, then stays in place.
ax-no-mobileNo animation at 767 px and below. The content simply appears.

Try it

Scroll the page up and down past these two. The left one repeats, the right one stays once it has arrived.

ax-rise-3d ax-repeat
ax-rise-3d ax-once

To make the whole site play once, set REPEAT_ALL = false at the top of the snippet. Then only elements with ax-repeat repeat.

Groups: stagger and sequence

Put a class on the container and its children animate one after another. You never edit the children. Two modes cover most cases.

Class on the containerWhat it does
ax-staggerEvery child gets the same effect with an even gap between them. Add a type such as ax-zoom-in, and ax-step-N to set the gap (default 100 ms).
ax-sequenceEvery child gets its own effect, speed, delay and gap, all written on the container as ax-n1-..., ax-n2-... and so on.
ax-step-0No gap. Every child starts at the same time, each with its own settings.
ax-togetherAll children start when the container comes into view. Without it, each child starts when it scrolls into view, which suits tall containers.

Sequence builder

Set each child's effect and timing, then copy a single class. Paste it into the container's CSS Classes. The children need nothing.

Per-child classes

In a sequence, write ax-nK- followed by any class without its ax- prefix. n1 is the first child, n2 the second.

On the containerResult
ax-n1-tilt-rightThe first child uses ax-tilt-right.
ax-n1-delay-300 ax-n1-dist-lgThe first child's own delay and distance.
ax-n2-slow ax-n2-duration-1700The second child's own speed.
ax-n3-after-500The third child starts 500 ms after the previous one, instead of the container's gap.
ax-odd-fade-left ax-even-fade-rightOdd children (1, 3, 5) fade left, even children (2, 4, 6) fade right.
ax-last-popThe last child pops.
ax-nocycleIf there are more children than ax-nK settings, the pattern repeats (n1, n2, n3, n4, n1...). This switches that off.

When the same property is set in more than one way, ax-nK wins, then ax-last, then ax-odd and ax-even. Children without a setting inherit the container's effect, or ax-fade-up.

Where it can go

Any container works: a section, an Elementor container, a header, a footer, a menu, a list, a gallery or a table. The snippet finds the real children for you. If there is a single wrapper in the way (such as .elementor-widget-container), it looks inside. Hidden elements, off-screen "skip to content" links and zero-size elements are ignored, so a Header Footer Elementor header resolves to its real columns.

ClassWhich childrenTypical use
noneThe container's real children, found automatically.Card rows, headers, footers, columns
ax-items-directOnly the direct children. Do not look inside wrappers.When one wrapper should animate as a whole
ax-items-liEvery li inside. Sub-menu items arrive with their parent.Menus, lists, icon lists
ax-items-imgEvery image inside.Galleries, logo walls
ax-items-a ax-items-p ax-items-h ax-items-tr ax-items-btnAll links, paragraphs, headings, table rows, or buttons inside.Link lists, steps, pricing tables
data-ax-items="selector"Any CSS selector you choose.Custom markup (Elementor Pro: Advanced, Attributes)

Examples

Whole sections, cards, headers and footers

An effect class on a container animates the container as one piece. Add ax-cascade and the content inside it animates too: first the container, then its heading, text, image and buttons, one after another with the same effect.

Class on the containerWhat happens
ax-fade-leftThe whole card, section, header or footer fades left as one piece.
ax-fade-left ax-cascadeThe container first, then every piece of content inside it, one by one.
ax-cascade ax-step-120Sets the gap between content pieces (default 80 ms).
ax-cascade ax-slow ax-delay-300The container's speed and delay apply to the content too, and the content starts after the container.

On a tall section, each piece animates when it reaches the screen, not all at once with the container. Whatever part of the section is visible on screen animates straight away, including the bottom edge of the viewport.

  • Sliders, carousels, video, iframes, tables and forms are treated as one piece. Their inner slides are not animated separately.
  • Content that is created later by JavaScript (sliders, tabs, AJAX) is picked up automatically.
  • An element that has its own ax- class animates by itself and is skipped by the cascade.
  • After an animation finishes, the snippet removes its own rules, so a card's hover effects, transitions and transforms behave exactly as before.

Page load

Elements that are on screen when the page opens, such as a header or a hero, animate on page load. The snippet waits until the page has finished loading (images and fonts) before it starts, so the animation is actually seen. A header that was already visible no longer plays backwards first: the container stays hidden until the snippet has prepared its children.

These settings sit at the top of the script. Change them there.

var REPEAT_ALL = true;      // false = play once; only ax-repeat elements repeat
var WAIT_FOR_LOAD = true;   // false = start immediately, on DOM ready
var WAIT_MAX = 3500;        // ms: never wait longer than this for a slow load
var LOAD_DELAY = 0;         // ms: extra wait after load, for every animation
var PRELOADER = "";         // selector of your page loader, e.g. ".preloader, #loader"
var PRELOADER_MAX = 10000;  // ms: stop waiting for the loader after this long

To delay a single element after load, give it ax-delay-400. If your site shows a preloader, put its selector in PRELOADER: animations stay paused while it is visible and start the moment it goes away.

Target any class or ID

You do not have to type classes into Elementor. In the script, the TARGETS list takes a CSS selector, the classes to add, and optionally a selector for the children.

Inside the script
var TARGETS = [
    ["#hero-title",   "ax-split-flip ax-slow"],
    ["#hero-image",   "ax-iris ax-slow"],
    [".service-card", "ax-rise-3d ax-delay-200"],
    ["#main-menu",    "ax-stagger ax-fade-down ax-step-80", "li"],
    [".gallery",      "ax-stagger ax-zoom-in",              "img"],
    [".team-list",    "ax-sequence ax-n1-fade-up ax-n2-zoom-in", ".member"],
];

The selector is ordinary CSS: #id, .class, .parent .child, h2. Keep a comma after each line. A wrong selector never breaks the page; it logs a warning to the console. In Elementor, set an ID under Advanced, CSS ID without the #.

Troubleshooting

I added a class but nothing animates, or settings are ignored

First confirm the site is running the current snippet. Open the browser console on your page and type AX_VERSION. It should print 3.4. If it prints undefined or an older number, paste the complete snippet into WPCode again, click Update, and clear your cache.

Then type axInfo(), or axInfo("#your-section-id"). It prints a table of the elements the snippet found, how many children each has, and their state. The class must be on the widget's outer wrapper (Elementor's CSS Classes field does this) and the snippet must be set to Site Wide Header.

Elements stay invisible

A caching or optimisation plugin is almost certainly delaying the script. Exclude this snippet from "Delay JavaScript". If the script never runs, everything becomes visible again after five seconds as a safety net.

Nothing animates inside the Elementor editor

That is intentional, so that editing is not disturbed. Use the preview or the published page.

A header or container animates as one block instead of its children

The snippet animates the children of the element that carries the class. Put the class on the container that directly holds the items you want to animate, or use ax-items-li or data-ax-items to name them. Use axInfo() to see which children were found.

I want every animation to play only once

Set REPEAT_ALL = false in the snippet. Or leave the default and add ax-once to individual elements.

New content appears after a popup or an AJAX load

Run window.axRefresh(); after the content is added.

Old browsers and reduced motion

Visitors who ask their system for reduced motion, and browsers older than 2022, see the content normally with no animation.
